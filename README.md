## 🌟 About

**Isha** is a full-stack AI chatbot project. A Python server handles the chatbot logic and serves a clean web UI, so users can chat with the bot directly from their browser. It's a great starting point for anyone learning how to connect an AI model to a real web application.

> 📄 A step-by-step walkthrough is also included in **`Chatbot Setup Guide.docx`**.

## ✨ Features

- 💬 Real-time chat interface in the browser
- 🧠 AI-powered responses via a Python backend
- 🎨 Custom HTML templates and static assets (CSS/JS)
- ⚡ Lightweight and easy to run locally
- 🔧 Simple structure that's easy to extend and customize

## 🛠 Tech Stack
